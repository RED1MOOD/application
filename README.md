# 🎵 تطبيق موسيقى والقرآن الكريم

تطبيق متكامل يجمع بين الموسيقى والقرآن الكريم في منصة واحدة فريدة. يوفر تجربة استماع احترافية لتلاوات القرآن والموسيقى العربية بجودة عالية.

## ✨ المميزات الرئيسية

- 🎙️ مكتبة شاملة من تلاوات القرآن الكريم من قارئين متعددين
- 🎵 مشغل موسيقى عالي الجودة مع دعم صيغ متعددة
- 📋 قائمة تشغيل مخصصة وقوائم مفضلة
- 🔍 خاصية البحث السريع والتصفية المتقدمة
- 📱 واجهة مستخدم سلسة وحديثة
- 🌙 دعم الوضع الليلي والنهاري
- 📥 تحميل الملفات للاستماع بلا إنترنت
- 🎨 تصميم جميل متوافق مع Material Design 3

## 🛠️ التكنولوجيا

- **اللغة:** Kotlin
- **الإطار:** Jetpack Compose
- **نظام إدارة البيانات:** Room Database
- **المشغل الصوتي:** ExoPlayer
- **البيئة:** Android SDK 34+

## 🚀 الاستخدام

1. استنساخ المستودع
2. فتح المشروع في Android Studio
3. تثبيت التبعيات عبر Gradle
4. تشغيل التطبيق على محاكي أو جهاز فعلي
